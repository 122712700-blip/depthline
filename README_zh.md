# depthline

**面向移动机器人的纯几何单目避障模型。**
模型的世界只由两个通道构成——**深度图**和**线图**，仅此而已。不看颜色，不看材质，不认类别。

## 为什么这样做

大多数学习型避障把 RGB 喂进大网络，然后祈祷它能泛化。事实上光照、纹理、没见过的物体随时击穿它，而且失败方式是**自信地错**。

**depthline 反向下注**：把输入砍到纯几何。一张归一化逆深度图 + 一张结构边缘图（线图），对场景、昼夜、墙面颜色、物体类别天然不敏感。放弃的能力（门槛和砖分不开）被明确命名、用可调阈值处理——而不是藏进一个会静默失效的分类器里。

模型很小（≈1–2 M 参数），**训练不需要人工标注**，重感知（单目深度）是插件而非训练对象，因此可以在端侧 NPU 上跑。

## 工作原理

```
RGB ─► 单目深度（插件 ZipDepth / DepthAnything DA2）─► 相对逆深度 Q̂
                                          ├─► 线图 E   （深度梯度断崖边缘）
                                          ├─► 置信度 C （空洞 / 低纹理标记）
   稀疏米制锚点（ToF / 人工标定 / 模拟器）─┘        │
                                                    ▼
                                    小 CNN ─► 极坐标代价栅格
                                                    │
                                                    ▼
                                    规则层：前进 / 转向 / 停车
```

三条设计承诺：

1. **输入表征冻结。** 模型永远只看 `(Q̂, E, C)`。尺度、安装高度、内参全部被归一化与域随机化吸收——所以模型是迁移的，不是重训的。
2. **其余一切都是插槽。** 深度网络、米制来源（3 路 ToF 锚点 / 一把卷尺 / 模拟器）、教师工具链、决策算法——皆可替换（插槽总表见 `docs/design.md`）。
3. **靠蒸馏训练，不靠标注。** 离线"教师"把 100+ 帧融合成稠密米制占用标签（纯 numpy 2.5D 高程图实现，零第三方依赖）；在线单帧"学生"学习逼近它。仿真场景提供多样性，但输入用**真实深度噪声模式**渲染。全程零人工标注。

## 快速开始

```bash
git clone https://github.com/122712700-blip/depthline.git
cd depthline
pip install -e .

# 生成合成数据段（无需真机，演示数据契约）
python -m src.data.make_synthetic --out demo/seg_synth --frames 60

# 校验任意数据段是否符合契约
python -m src.data.validate demo/seg_synth

# 运行阶段2表征模块冒烟测试
python tests/test_stage2.py

# 运行离线几何教师管线（生成伪标签）
python -m src.teacher.run demo/seg_check --res 0.05
```

教师管线输出（`<seg_dir>/_teacher/`）：
- `dh.npy` — 网格离地高度场
- `occ.npy` — 4类占用（free / 低矮可跨 / 障碍 / unknown）
- `cnt.npy` — 每格观测计数
- `report.json` — 覆盖率、分类统计、耗时
- `dh.png` / `occ.png` — 可视化（验收：地面≈0、墙成柱、椅成台）

## 已知限制（如实声明）

- 纯几何输入分不清"可跨的门槛"和"该停的砖"（同高度即同几何）——用你调的高度阈值处理。
- 感知视场 = 相机视场：侧后方障碍需要额外传感器或"停下载入"行为。
- 玻璃与镜面会骗过**任何**单目方法；depthline 通过"锚点 vs 深度不一致"检测将其标记为未知区域，按障碍处理，绝不按可通行处理。
- 这是研究级避障层，**不是认证安全系统**。实体机器人必须保留独立硬件急停（ToF TTC / 防撞条）。
